# GSVN TV APK

Android TV / Google TV utility. This public repository contains the README and release downloads only; the source repository is private.

- [Download the latest APK](https://github.com/mjnamjkaze/gsvn-tv-apk/releases/latest/download/GSVN-TV.apk)
- [All releases](https://github.com/mjnamjkaze/gsvn-tv-apk/releases)

The app does not send usage telemetry, device identifiers, or TV app/package inventories. Network requests are used for update checks/downloads and the weather service.
